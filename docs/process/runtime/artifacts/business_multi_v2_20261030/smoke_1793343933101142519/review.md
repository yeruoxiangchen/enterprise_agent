技术支持 · 我的Windows电脑用SSH连接仓库时提示Permission denied，已经检查网络。
SSH连接失败提示“Permission denied”通常与公钥认证配置有关。请确认以下几点：

1. **公钥是否已正确上传到仓库服务器**：确保你已将本地生成的公钥（`.pub` 文件内容）提供给管理员，并且已正确登记在仓库服务器上 [S1]。
2. **SSH配置是否正确**：检查本地的SSH配置文件（通常位于 `~/.ssh/config`）是否正确设置远程仓库的地址和端口。
3. **SSH密钥权限是否正确**：确保私钥文件（如 `id_rsa`）的权限设置为 `600`（即只有文件所有者可以读写）。
4. **SSH代理是否运行**：确保SSH代理（`ssh-agent`）正在运行，并且私钥已添加到代理中。可以使用以下命令检查：
   ``` 
   ssh-add -l 
   ```
   如果没有列出私钥，可以使用以下命令添加：
   ``` 
   ssh-add ~/.ssh/id_rsa 
   ```

如果以上步骤都已确认无误，但问题仍然存在，请提供更多详细信息，例如：
- 你使用的SSH客户端版本
- 你尝试连接的仓库地址
- 你使用的SSH密钥文件路径
- 你是否使用了SSH配置文件（`~/.ssh/config`）

这些信息将有助于进一步诊断问题。
